## Helper scripts

Usage: 


###  parse-nested-quast-runs

Pulls all quast runs in the current and all subdirectories that you pass as an argument. 


```
# Search a specific directory
python quast_summary.py /path/to/your/assemblies

# Search the current directory (both do the same thing)
python quast_summary.py .
python quast_summary.py

# See the help menu
python quast_summary.py -h
```
